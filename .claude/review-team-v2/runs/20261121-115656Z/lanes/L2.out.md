## Checked and fine
- Picked range overwritten by default: ruled out by panel.js:605 (!rangePicked) and rangePicked set before early return panel.js:843.
- Older valid read overwrites newer valid: ruled out by panel.js:627 (read < defaultRangeApplied).
- Waiters never resolved: ruled out by panel.js:632-635 (newest read always runs final then; middle handler cannot throw).
- Sync throw from settings.get: ruled out by panel.js:625 (inside then) and 630 (rejection swallowed).
- Missing settings API on old host: ruled out by optional chaining panel.js:596, 625; undefined range fails RANGE_DAYS.has (627) and keeps 7d.
- Unknown value ('1y') → keep: ruled out by panel.js:627; test panel.test.mjs 'an unknown or unreadable Default range...'.
- Out-of-enum but 'custom' default: ruled out by RANGE_DAYS check (627) — 'custom' not in map.
- Stale fallback load clobbering a picked range: ruled out by rangePicked-independent load only when !report && !busy (panel.js:611 and 599); picked load in flight sets busy.
- Background usage.changed load during firstLoad: ruled out by state.again path (panel.js:48-51, 72-76).
- Clear of custom range going to stale 7d: ruled out by panel.js:158 reading state.defaultRange (sole reader).
- Flash of 7d before 30d: acknowledged in pack as settled (panel.js:49-50 design); not re-raised.
