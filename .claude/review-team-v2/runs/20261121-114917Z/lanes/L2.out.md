## Checked and fine
- out-of-order default reads: ruled out by panel.js:619-625 (newest-only write and clear) with test 'older Default range read'.
- picked range lost to late default: ruled out by ranges click rangePicked set before same-range return (panel.js:844-845) and applyDates (:296); tests 'unknown or unreadable' and 'no-op pick'.
- failed picked load replaced by default: ruled out by firstLoad only moves when !rangePicked (:605); retry uses state.range via load() test '90d, 90d'.
- usage.changed during first read: ruled out by load() busy -> state.again (:48-51, :72-76) then firstLoad moved -> load(); test 'background load'.
- hung read: ruled out by try/catch (:624) plus 1.5 s fallback (:599); 'slow read' test passes.
- Enum/RANGE_DAYS mismatch: RANGE_DAYS is a Map (query.mjs:3), .has valid; enum matches.
- Flash of 7d before 30d: known, design choice per lead suspicion; not re-raised.
- Stale built html: scripts/build.mjs output byte-identical to panel/index.html.
